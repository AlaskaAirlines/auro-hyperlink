## Overview

Hyperlink is one of the most used components on our website. It comes in three styles: a standard inline link, a navigation link (`type="nav"`), and a call to action link (`type="cta"`) that looks like a button. Each style has different properties.

## Features
* Three link styles: standard, navigation, and CTA button
    * Standard: an underlined text link for stand-alone or inline links
    * Navigation: links that aren't inline, underlined on hover and on focus; navigation links can include an icon on either side of the label
    * CTA button: a link that looks like a button; shows a new-window or external-link icon when it opens in a new window (`target="_blank"`)
* States: default, hover, and focus
* Dark mode (`appearance="inverse"`) available for all three styles
